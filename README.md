# artemiod.github.io

La raíz de `https://artemiod.github.io`. Existe por un solo motivo: **`app-ads.txt`**.

Google AdMob exige ese archivo para seguir publicando anuncios, y el estándar obliga a servirlo en
la **raíz del dominio** que figura como sitio web del desarrollador en la ficha de Google Play. Una
subcarpeta no sirve: el rastreador pide `https://artemiod.github.io/app-ads.txt` y ninguna otra
dirección. Por eso no vive junto a la política de privacidad, que está en
[PrivacidadBiciBa](https://github.com/ArtemioD/PrivacidadBiciBa).

La línea declara que Google puede vender publicidad en nombre de este editor. Sin ella, un anunciante
que reciba una oferta de inventario de la aplicación no puede comprobar que sea legítima.

Se actualiza solo si cambia el ID de editor de AdMob o si se suma otra red publicitaria.
